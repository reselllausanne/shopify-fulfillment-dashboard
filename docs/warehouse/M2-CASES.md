# Module Entrepôt et Partenaires — statut des 150 cas M2 (lot 1)

Revue indépendante en lecture seule du worktree `feat/warehouse-partners-lot1`, faite le 28 novembre 2026 entre 04 h 50 et 05 h 10 pendant que le code du domaine et les écrans changeaient encore. Chaque cas de la feuille de route a été confronté au code réel : la fonction a été ouverte dans `lib/warehouse/**`, la contrainte ou le trigger vérifié dans `prisma/migrations/20261128040000_warehouse_lot1/migration.sql`, et le test cité relu dans `lib/warehouse/__tests__/` (suite exécutée six fois sur la base locale jetable : 6 fichiers, 91 tests, verts quatre fois ; deux exécutions ont eu chacune un échec différent, non reproduit, alors que d'autres exécutions tournaient sur la même base). Un commentaire ou un type seul ne vaut pas preuve. « déjà couvert » porte sur la partie logicielle du lot 1 ; ce qui dépend d'une imprimante, d'une douchette ou du réseau du dépôt est noté « à vérifier sur matériel ». Les cas marqués L2, L3 ou L4 sont « reporté », avec le socle déjà posé. Les mesures de charge et de restauration citées viennent de `docs/warehouse/recette/*.json` : elles ont été faites sur un poste local, pas sur le VPS. Dans la colonne Preuve, les chemins sont relatifs à `lib/warehouse/` sauf mention contraire, et les numéros Q-xx renvoient à `docs/warehouse/DECISIONS.md`.
